Используй скилл `recruiting-ats`. Только чтение — ничего не меняй.

Период: $ARGUMENTS дней (по умолчанию 30; допустимо 7, 30, 90).

1. `get_dashboard { days }`.
2. Отчёт: KPI с изменением к прошлому периоду (добавлено, переходы, офферы, наймы, отказы, time-to-hire), воронка по этапам, топ источников, причины отказов (кандидат / компания), вакансии (в работе, офферы, наймы, дней открыта), нагрузка по рекрутерам, зависшие кандидаты.
3. Только реальные числа из ответа; укажи период и `generatedAt`. Выводы — коротко, по фактам.
