Используй скилл `recruiting-ats`. Только чтение — ничего не меняй.

1. `get_dashboard { days: 7 }` → `my.queue`, `my.mine`, `stale`, `kpi`.
2. `get_notifications { view: "unread", limit: 20 }`.
3. Покажи: что требует моего действия сегодня (очередь с числом дней на этапе, сначала самые долгие), новые события по моим кандидатам, короткую сводку недели (добавлено, переходы, офферы, наймы — с прошлой неделей).
4. Предложи конкретные следующие шаги по 2–3 кандидатам из очереди.
