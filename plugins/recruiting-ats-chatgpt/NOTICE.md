# Сторонние материалы

Скиллы `interview-design`, `hr-screening`, `tech-interview-dotnet` и `interview-debrief` написаны для Recruiting ATS. Методика структурированного интервью (типы вопросов, уточняющие вопросы, признаки сильного и слабого ответа, шкала, оценочный лист, bias-aware-подход, список недопустимых вопросов) переработана на основе:

- `human-resources/skills/interview-prep` из [anthropics/knowledge-work-plugins](https://github.com/anthropics/knowledge-work-plugins) — Apache License 2.0, © Anthropic;
- `skills/hr-interviewing` из [tuanductran/hr-skills](https://github.com/tuanductran/hr-skills) — MIT License, © 2026 Tuan Duc Tran.

Тексты переведены, сокращены и адаптированы под процессы и шаблоны ATS; исходные файлы не копировались без изменений.
